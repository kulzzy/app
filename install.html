OPEN KULZZY RADIO

📱 ANDROID PHONES

  1. Open this page in Google Chrome.
  2. Tap INSTALL KULZZY RADIO above if the installation prompt appears.
  3. If nothing happens, tap Chrome's three-dot menu.
  4. Select Install app or Add to Home screen.
  5. Follow the instructions to finish installing.

🍎 IPHONE

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Select Add to Home Screen.
  4. If Open as Web App appears, enable it.
  5. Tap Add.

Installation options depend on your device and browser. If installation is unavailable, you can still use Kulzzy Radio directly from its website.
